随着毕业后进入工作和生活，真正接触社会后，愈发觉得自己是一个不太喜欢宏大叙事的人。从听的歌、看的影视剧，到最近常听的播客，那些宏大叙事的主题和内容都难真正地打动到我，我也不喜欢精英言论，相比之下，更喜欢那些私密的、具体的，能让我共鸣的情感。

我不关心社会，我只关心我自己的生活。

## 同学小聚

这周六伟哥来深圳玩，大家约着一起吃大仟里的雪乡情，六点半集合。

雄先到，排了个大桌号，说是得等位一小时。我和宗霖到了之后，觉得实在太久，就临时换了三楼的江西土菜。

其实我还蛮想吃东北菜的，确实很久没吃了，加上我对雪乡情的印象一直还不错。不过几个东北同事都说一般般，我对东北菜确实也没什么发言权。

江西菜看着还行，味道就是正常商场店水平，无功无过。

被寄予厚望的莲花血鸭江西辣版，完全没达到预期。在我看来最多就是个普通中辣的水平，伟哥还是永州人，也觉得完全比不上永州血鸭。反而是烟笋炒腊肉还不错，很下饭，挺合我这个湘西人的口味。

<Image src="/api/image/assets/posts/weekly_16_莲花血鸭.webp" alt="江西土菜" />

吃完后，大家跟着宗霖去了一家清吧，一人点了杯酒。

我想到最近播客里听到的「瞎掰王」游戏，就找了个小程序，开玩。语言类游戏真的有意思，几个人一起胡说八道，欢声笑语里时间过得很快。瞎掰王最大的乐趣，就在于每个人都能参与进去。

玩下来也发现自己知识面还是太窄了，算是印证了「人无法想象出自己没见过的东西」这句话，掰来掰去，都是在自己的知识储备里打转。

时间过得很快，喝酒、聊天、玩游戏，很开心。最开心的，大概还是发现大家都没怎么变吧！

## AI

<Tweet id="2090416137720999992" />

X 上看到这篇帖子，有感而发。

平时用 Agent 做事，经常会遇到是不是蹦出几句黑话，夹着着大量琐碎的信息。

GPT 尤其明显，特别喜欢在一些非核心事项上大做文章，比如测试、健壮性建设等，经常在我预期之外加了大量的低收益内容。又或者方案讨论时，某个已经明确被否决的选项，被当成重要记录写进注释或者 PR body 里。

这周从同事那儿学到了一个提示词：
> 我有 ADHD 和注意力缺陷。

结合我平时经常说的，最后变成：
> 我有 ADHD 和注意力缺陷，请输出的信息尽可能精简、准确、易懂。

做方案探讨的时候非常有效。

如果涉及到不是自己领域的问题，还可以加上一句「我有智力缺陷」。虽说方法有点抽象，但Agent 往往会主动降低理解门槛，用更简单的语言或者类比来把事情讲清楚。

除此之外，我还有一个痛点：项目里配置 N 个 skills，尤其是哪些规范类、期望 Agent 在执行过程中自动匹配触发的，在实际开发时并不能保证每次都严格遵守。

所以我现在的做法是，开发前先让 Agent 自己匹配 Skills，不做过多的指定。一轮开发完成后，再主动点名规范类的 Skill，让 Agent 针对产出再优化一轮。完成后才进入功能验收和 code review。

这样做是为了确保产出的规范尽可能接近预期。理论上当然是轮次越多越稳，但在工作里适当即可。

我一般会用 `/itaober-guidlines` 做一轮，让这次改动的代码尽量符合最佳实践。如果代码变更比较大，会补一轮 `/ponytail-review`，避免 Agent 排泄。

`/itaober-guidlines` 参考了 [Karpathy Guidelines](https://github.com/multica-ai/andrej-karpathy-skills/blob/main/skills/karpathy-guidelines/SKILL.md)：
- 编码前先思考：明示假设，明示困惑和权衡。
- 第一性原理：把问题拆到本质，从根本上推导真正解决问题的方案，而不是顺手抓一个最省事的做法。
- 简单优先：只写解决问题所需的最少代码，不做投机性的扩展。
- 外科手术式改动：只动必须动的地方，只清理自己制造的烂摊子。
- 目标驱动执行：先定义成功标准，再循环直到验证通过。
- 注释规范：只解释代码本身说不清的东西，解释 why，不复述 what。
- 纠正与汇报：接受纠正就直接改，最终只汇报交付状态。

随着大模型越来越聪明，Skill 更多是在辅助模型、明确方向和收敛行为的边界，而不应该是事无巨细地教它做事。这也是为什么现阶段 `grill-me` 比 `superpowers` 更让人喜爱的原因。

### 电影

- 《欢迎来龙餐馆》：周五晚上去家附近影院看的深夜档。在网上已经夸遍了的高预期下，看完依旧觉得很好看。

  有两点让我印象比较深。一点自然是顶级 ABC 托尼王，几乎承包了我的全部笑点；另一点则是徐福和陈俊生，无论在任何情况下都保留着尊严，没有卑躬屈膝。

  现在想把电影拍的好看，我觉得编剧写故事的能力太重要了。故事不能俗套，情节不能轻易被观众猜到，主题又不能悬在空中。龙餐馆在这几点上都做得很好，用厨子的视角去讲一个反战故事，发展既在意料之外，又在情理之中。

  结尾赛夫没有回头的留白，也证明了导演的功力。
