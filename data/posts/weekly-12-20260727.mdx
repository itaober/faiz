> `2026-01-26` 至 `2026-06-24`

确实是很久没有更新周记了，根本的原因还是因为我的懒惰。我对「记录」这件事情的依旧怀有极高的热情，但把更多的琐碎的内容放在了 <Link href="/memos">Memos</Link> 上，则怠慢了相对较长的 Post。一周没更新，后续更新内容的工作量就会变多，其实我不应该把这个事情理解成是工作量，但事实上这的确会给到我一些压力。

这半年发生了蛮多事情，最大的变动就是从 HST 离职，离开了长沙，到深圳回流了老东家。随着工作的变更，生活又重新开始。

每次重新开始都先想着怎么做改变，一忙碌起来又一切如常。停下来想想的时候，其实只要能一直往好的方向走着，就挺知足了。

## 长沙

> 回忆回忆在长沙发生的事。

### 过年

年前约了搭孙宇的车一起回去，中午的时候得知说表姐从江西来长沙的顺风车出了车祸，幸好人都没事。我们先去浏阳医院接她们，然后去托运站取行李，兜兜转转加上堵车，大半夜才到家。

<Image src="/api/image/assets/posts/weekly_12_报废的顺风车.webp" alt="报废的顺风车" />

今年过年最大的感受就是完全没年味，爷爷奶奶去世了，回来的亲戚也少了，街道办的人支个喇叭喊着不准放烟花炮竹，让这次春节淡的就像是一次普通的长假。

<Image src="/api/image/assets/posts/weekly_12_年夜饭.webp" alt="年夜饭" />

年初二去了外婆家，住了一晚。在乡下相较于县城年味又稍重一些，也是把塞尔达的水之神兽给打过了。

<Image src="/api/image/assets/posts/weekly_12_外婆家的表弟们.webp" alt="外婆家的表弟们" />

老家村子坡上的木房都已经是危房，很难抵挡一些极端的自然天气，村里很多人都在村外坡入口买了地基建水泥房，我爸妈也买了一块。这次回去路上路过看了一眼，说实话我看不出好坏，也没啥意见，只是觉着不错，也许这里就是未来爸妈养老的地方，血脉循环，让我想起葬在那山上的爷爷奶奶。

<Image src="/api/image/assets/posts/weekly_12_老家地基.webp" alt="老家地基" />

常规地还是约了鸡哥一起吃了早餐，上了网，吃了顿烧烤。现在回老家还能约见的老同学也只有鸡哥和老孟了。

<Image src="/api/image/assets/posts/weekly_12_好吃街.webp" alt="好吃街" />

### 龙少订婚

龙少在年前跟他女朋友订婚了，印象中他们在一起的时间并不长，听到这个消息还是很恍惚，前段时间还是经常约着打麻将，就在那么一瞬间就发现我们已经是外人了。

作为朋友我是真心认为他们挺般配，也希望他们幸福。

### 面试

年前彪哥说他那有个 HC，问我有没有想法再去深圳，我说可以试试。接着就是改简历，准备面试题。

HR 先是打了电话了解情况，我把该说的都说了一遍，问到期望薪资的时候不知道为啥我脑子一抽，说了一个很低的数，说完我心里立马就后悔了，一致怀着忐忑的心情去准备后面的面试。

一面是斌哥面，二面是彪哥，然后再是 HR 面。每轮基本都聊了一个多小时，我也是尽可能地多表达和展示。终于最后 HR 问我，之前电话里聊的信息有没有要变的，总算是有机会把期望薪资报了一遍，接着就是等通知。

在一个工作日的下午，HR 打来了电话说面试通过了，聊了聊待遇以及入职相关，心里的石头总算是落地了。

### 离职与年终

往年是在四月中发年终，但今年有小道消息传出说年终会 3 月 10 号发，于是我想着 10 号后再提离职。到了时间没发，接着又是传三月内发，传着传着有说最后一周发，都落了空。

在某个周三的晚上，我从厕所出来，看到 Leo 在走廊抽烟，想着这或许是最好的时机，明天上午他就要回深圳了，离职这种事好歹得当面提。便跟 Leo 找了个小会议室，提了离职，顺便问了年终，Leo 答应我说会给我发，我心里算是踏实了。

接着就是做工作和生活上的交接，四月初正式结束这份工作。在 HST 快三年的时间里，遇到了很多问题和挑战，也成长了许多，逐渐能独挡一面，我很感激。

### 清明

奶奶刚过世一年，按习俗来说是不应该在清明的时候去扫墓的，正好四月初离职休假，我便提前清明一周回了趟老家。

也是今年我才发现家里蛮多长辈信基督，竟然清明不愿意来扫墓。我想起小的时候在吃饭前，爷爷奶奶都会让我到门缝里闭着眼祷告几分钟，我那时候想的都是保佑健健康康，类似生日祝福那样的吉祥话，祷告完再划十字圣号，念一句「阿门」。隔一段时间，亲戚们还会聚在一起做一次集体的祷告，印象中小姑父家是一个聚点，在祷告的房间里还挂着一面红色的十字架旗帜。历史我没去考究，猜测也许是多年前有传教士到我们这儿传过教，因为我们高中学校里还有一个废弃的基督教堂。

给家里的过世的祖先们都挂了清、扫了墓，在家又待了一天，回了长沙。

## 深圳

### 租房

在深圳租房必然是一件大事，要租到满意的房子并不容易。

落地第一天跟着在小红书提前约好的中介去看了几套，有满意的但价格实在是超出了预算，线下看的房子远远没有小红书上推的那么好，落差很大，半天下来也算是摸清了一些套路：几乎所有社交媒体上的房子图片都是用来引流的，越好看房时间地点后，会给你打电话说他有事来不了，让他碰到带你看，不一会儿那个「朋友」就骑着个电瓶车过来了，看了一两套房子之后发现这都是虚假宣传。

我这次深受其害，最后还是碰到另一个在附近瞎逛的中介，跟着他租了灵芝的一套一室一厅。

<Image src="/api/image/assets/posts/weekly_12_电脑桌.webp" alt="电脑桌" />

住了几天发现对面楼顶的水泵总是发出「滋滋滋」的噪音，去深圳的便民服务举报了两次，都是说联系了房东会处理，然后不了了之。

唉，三个月下来，我都快习惯这个声音了，罢了，明年到期后一定要换个房子住。

### 工作

作为公司的回流员工，工作上的上手自然是更快，适应了一周不到，便开始高强度地正式投入开发。

我入职第二天开了 Q2 的 All Hands，上周开了 Q3 的，也意味着我已经入职三个月了。

回顾这三个月的工作感受，一方面是 AI，现在所处的项目团队是一个 AI-Native 的开发模式，前期的探索已经摸索出了一套适合团队 & 个人的开发范式，这个提效是立竿见影的，尤其是在公司提供的 Claude 和 Codex 双持下，大跃进式的提升。入职到现在的三个月没写一行代码，从以前的代码洁癖也逐渐转向成 API/架构设计上的洁癖。
另一方面则是对跨团队协作重要性的认识，当下工作内容中编码借助 AI 已经是极高效且异步的，在这异步产出的过程中，大量的精力都花在了跟其他人/团队的沟通上。问题也自然随着对接的人/团队变多而雪花般的扩散，如何处理好这些问题变成了工作中的一大部分。

记得我应届生时的导师在某次 one one 时曾跟我说，工作对个人而言最重要的就是工作体验。这是一个大的话题，薪资、工作内容、周围的同事乃至办公环境，都是工作体验的一部分。抛开纯粹的工作内容，这三个月认识了新的同事，聊得来的则成了朋友，每天中午、晚上吃饭时聊上一些「爆」的话题，下午的水果，晚上的健身，偶尔聚聚餐，这些都让我感觉挺快乐的。

总而言之，再回这里，既熟悉又陌生，每天有很多事做还挺充实，我让我少有空闲去思考了很多不切实际的幻想，今年得努努力了。

### 麦理浩径徒步

六月初组内团建，去了一趟香港，徒步麦理浩径，之前一直着急去办的港澳通行证也终于派上了用场。

我跟姚师傅选了困难路线，从徒步入口走了不到十分钟，就下起了雨，我们便套上雨衣开始冒雨徒步。一路上走走停停，到了浪茄湾，休息了会，打算让约好的快艇提前来接去晚上吃海鲜的地方，没想到对方以下雨来不了为由退单了。无奈只能再跨山去到西工东坝，打的去了目的地，路上的士师傅开得很猛，由于 HK 是右舵车的缘故，看着总是像要撞上路边的样子，好不习惯。

晚上吃完海鲜，饭后散步拍了拍照，又下起了大雨。我们躲进了一家甜品店吃了份甜品，等约好的车接回深圳。

坏天气给徒步带来了挑战，也让回忆更难忘些。

### AI

这半年一路陪着 Codex 从 5.2 到 5.6 Sol，Claude 从 Opus 4.6 到 Fable 5，能力越来越强，回过头看去年做的很多 AI 相关的探索，以及网上的最佳实践，都逐步被大模型或大模型厂商的 Agent 能力替代掉。

有时候刷到一些博客，里面会记录这很多当时新鲜，现在开起来却过时的内容，我挺羡慕的，我对记录这种非真理，或者说非永恒的真理，有着一种羞耻感，我常常不愿意这么做，所以看到别人能记录下这些过程真的很羡慕。

那么我也应该尽可能去摆脱这份羞耻感。

Claude Code 作为 Coding Agent 已经足够强大，我日常的使用姿势也是建立在其之上，写了几个适合自己且经常使用的 skills：

- itaober-guidelines：给 LLM 编码的行为准则，灵感来自 [Andrej Karpathy](https://github.com/multica-ai/andrej-karpathy-skills/tree/main/skills/karpathy-guidelines)，做了一些适配自己的调整；
- itaober-flow：plan - coding - chrome e2e - fix loop 的开发流；
- itaober-handoff：把当前任务整理成中立、脱敏、可接手的交接文档；
- itaober-review-prompt：把当前改动整理成可复制给其他 Agent 做 code review 的 prompt；
- itaober-session-summary：把当前 Agent session 保存为一篇可长期检索的 Markdown 工作总结；
- itaober-skill-polish：把某个 skill 反复调试后才趟通的做法，回填成对原 skill 的最小改进。

近一个月强烈地感受到了 UX 在 AI 时代的重要性，随着模型能力的提升，软件本身的复刻成本变得极低，技术上难有护城河，而「Taste」至少目前 AI 还不够好。

也经常在 X 上刷到一些设计师分享自己的 demo 或者 skills，我收藏了一些：

- https://emilkowal.ski/
- https://www.userinterface.wiki/
- https://transitions.dev/
- https://jakub.kr/
- https://benji.org/

这些设计理念都不约而同地更加重视人机交互的体验细节，风格也都偏 Linear 风一些，一眼简单、高级，我也在尝试让 AI 能基于这些资料开发一些我想要的效果。

AI 同时也极大地抢夺了我的注意力，让我很难沉下心来认真地看完一篇文章、库、plan 甚至问卷。网上互联网圈也全部都是 AI 的新闻，已经让我患上了 ADHD，这远比以前的流媒体时代更强势。

或许这需要更多的沉淀，以及找到办法来对抗它。

- 《一一》：往往还没有准备好，故事就已经进入了下一个篇章，而遗憾则贯穿始终，再来一遍也难有什么不同，人生好像在不停的重复。
- 《给阿嬷的情书》：东亚导演很会写那些羁绊或误会而改变了人一辈子的故事，恰好我很吃这一套设定。
- 《八仙！》：有爽感，有反转，人设也设定的很成功，好故事！尤其是最后一个反转让整个故事变成了一个大的骗局，我很喜欢。

### 音乐

- 《民歌蔡琴》：一次刷小红书看到了蔡琴在古早台湾综艺里面唱《渡口》，便听了这整张专辑，复古优质，蛮好。
- 《GUOXIA》：李佳隆确实是天才，但这张专辑远没达到我的预期，没能发挥出他的天分。当然，《白色月季》是好听的。
- 《答应我会幸福》：无需多言，神！强推《真心话就是大冒险》。

### 剧与综艺

- 《绝命毒师》 1-4 季：过程是最精彩的，但炸鸡叔死之后丝滑差点意思，之前每次跑步看一集，现在第五季只能断断续续地看了。

### 书

- 《龙族Ⅰ》：两次来回长沙高铁上看完的。衰，懦弱，暗恋，少年的要素拉满，很难不共情。高中龙三看了一半书被老师没收了，期待迟来的感动。

### 游戏

- 《塞尔达传说 旷野之息》：很早就想玩但 Switch 一直也没买，终于今年玩上了，神作，且在发布十年之后的今天依旧是神作。

### 博客

- 《罗永浩的十字路口》：着半年把我感兴趣的嘉宾基本都听，喜欢刘谦、张玮玮和大鹏这三期，真实地感受到了他们的真诚以及真诚背后跟我以为的他们带来的反差感，我喜欢听这些真实的不同的人生故事。
- 《半拿铁》：爱听互联网大厂的发家史，回去翻了一轮，把感兴趣的都听了；
- 《无聊斋》：除非遇到完全不感兴趣的主题，几乎每期都会听，更像是综艺级的播客，不用带脑子，跟着乐就好；
- 《纵横四海》：EP83，讲「奥德赛时期」的一本心理学书，很契合我当下的心境，说教会多一些。本来是想拿来当这篇的标题的，想了下还是算了。

## 最后

确实是很久没记了，很想一股脑地把能想到的事都写出来，但我很难把握这个粒度，只能尽可能把我主管认为的「大事件」记下来，算是给后续复更做一个承接。
